General CAD packager (pkg-2026-10-02a): how to deploy and run on the fleet.  Read SPEC.md first.

Code      s3://annotationprod/cad-disk-extract/_control/packaging_d3/code/      tree layout (pkg.py, pkgcore.py, coord_hook.py, adapters/, kit/)
Kit       s3://annotationprod/cad-disk-extract/_control/packaging_d3/kit_flat/  flat copy for convfleet kit sync
          (worker.py pkg.py pkgcore.py adapter_zen3.py coord_hook.py; add convfleet.py from your runtime)
Python    python3.9+ with boto3 >= 1.34 (CopyObject ChecksumAlgorithm, HeadObject ChecksumMode). No other deps.
Writes    only the fleet role (bim): dataset/packages/3d/<project>/, _state/packaging/, zenitude-data-3/_state/conv/package/.
          Guard: every write path needs PKG_ALLOW_WRITE=1 (kit/worker.py sets it). Nothing is ever deleted.

0. DRY RUN (read-only; needs the coordinator's approval of its numbers before step 2)
   mkdir -p /scratch/pkgplan && cd /opt/pkg (code/)
   for i in $(seq 0 15); do nohup python3 pkg.py plan --adapter zen3 --all --gz --shard $i/16 --out /scratch/pkgplan > /scratch/pkgplan/plan_$i.log 2>&1 & done
   -> /scratch/pkgplan/<job id>.plan.json.gz + summary.<i>_of_16.json (files, bytes, steps, zips, unresolved, resolved_by per project)
   Upload the summaries + logs (not required: the plans) to bim _state/packaging/dryrun/<date>/.
   Optional first (resolves SDS/2 job-folder library files that data-4 stored without a marker; plan again afterwards):
   PKG_ALLOW_WRITE=1 python3 pkg.py build-d4-index --procs 32      -> _state/packaging/cache/d4_index/{00..ff}.json.gz + DONE.json

1. DEPLOY the vpipe (your release path): kit_flat/* + convfleet.py -> _control/z3conv/package/ ; jobs key
   bim cad-disk-extract/zenitude-data-3/_state/conv/package/jobs.json (PKG_JOBS_KEY to change). Results/claims under
   _state/conv/package/ as for every vpipe. A result {status: fail, transient: true} = project lock held -> retry.
   Memory need_bytes = 4 GB + archive/8 (cap 64 GB); disk need_disk = 8 GB + archive size (cap 800 GB; SDS/2 zips build locally).

2. COORDINATOR HOOK (each round, after build_index wrote index.jsonl.gz)
   import sys; sys.path.insert(0, '<kit dir>'); import coord_hook
   conv_status['packaging'] = coord_hook.round(write=True)
   -> writes the jobs list (+ immutable index snapshot), _state/packaging/status.json, ledger.jsonl + ledger_index.json,
      appends removals_pending.jsonl (never applied). First round: ~225 create jobs (2,952 STEP placements at the 22:31Z index).
   Without convfleet: kit/run_package_standalone.sh N  (runs every job of the list once, N in parallel).

3. VERIFY (any time; read-only)
   python3 pkg.py verify --adapter zen3 --all            fast: S3-stored SHA-256 per object (composite multipart -> info)
   python3 pkg.py verify --adapter zen3 --all --full-hash streams the composite (multipart) objects
   Every check must be 0 (SPEC.md section 9).

Single job by hand (debug):  PKG_ALLOW_WRITE=1 python3 pkg.py job --job job.json --workdir /scratch/pkgwork/x
